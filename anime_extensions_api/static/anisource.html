AniSource anime discovery engine
Waking up the API — it sleeps after inactivity on free hosting, so first load can take up to a minute.

AniSource is an unofficial browser for the public AniSource API. Every title, image and stream is fetched live from third-party sources at request time — nothing is hosted, stored, or owned by this page. Playback availability depends entirely on the upstream source.
